# Prompt Guide Studio — Start-Tab Benutzung

## App-Name
Prompt Guide Studio

## App-Beschreibung
Prompt Guide Studio liest ein bestehendes Projekt, erstellt daraus belegte AI-Prompts, Manifeste und Exportpakete und hält Ergebnisse vor dem Anwenden prüfbar.

## Start-Tab in kurzen Schritten
1. **Original-Projekt wählen:** Im Feld „Project root / working tree“ den echten Projektordner auswählen.
2. **Sprachen setzen:** „UI language“ ändert nur die Oberfläche. „AI response language“ steuert die Sprache generierter Antworten.
3. **Projekt erfassen:** „Scan project metadata“ lesen lassen, bevor Prompt Builder, Create oder Export genutzt werden.
4. **Prompt prüfen:** „Build prompt preview“ ausführen und den erzeugten Auftrag vor dem Export kontrollieren.
5. **Export kontrollieren:** Im Export-/Output-Tab prüfen, bevor Dateien kopiert, ausgeführt oder an ein anderes Tool übergeben werden.

## Start-Tab Box: Standard-Routinen
- Scan project metadata
- Build prompt preview
- Open Export tab
- Refresh tree preview
- Open Output tab

Prompt Guide Studio

## Start Tab in Short Steps
1. **Choose the original project:** In the “Project root / working tree” field, select the real project folder.
2. **Set languages:** “UI language” changes only the interface. “AI response language” controls the language of generated responses.
3. **Scan the project:** Run “Scan project metadata” before using Prompt Builder, Create or Export.
4. **Review the prompt:** Run “Build prompt preview” and check the generated instruction before exporting.
5. **Check the export:** Review the Export/Output tab before copying files, running them or passing them to another tool.

- Scan project metadata
